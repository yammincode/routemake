# 驗收清單

每個功能一段，分三部分：

- **自動測試**：Claude 每次 push 前都會跑（`npm run test:db`、`npm run build`、`npm run test:e2e`），全部通過才 push
- **手機上怎麼測**：3–5 步，照著點，對照「應該看到」
- **📱 只能真機確認**：自動測試模擬不到的，要你拿手機實際試

使用方式：

- **每次更新正式版後**：跑一遍下面的「每次必跑」（約 10 分鐘），再試 Claude 列的「這次改動的項目」
- 平常改完功能：Claude 會同時更新這份清單裡對應的那一段
- 更新正式版前：Claude 會列出「這次改動的項目」（從這份清單挑出跟這次改動有關的段落 + 受影響的 📱 項目）
- 大改版或上線前：整份從頭跑一遍

測試帳號建議準備三個：**老闆**、**某館店長或定線員**、**一般顧客**（可以用兩支手機或一支手機 + 電腦）。

---

## 每次必跑（約 10 分鐘）

每次更新正式版後都跑這一份，確認最重要的幾條路沒有被改壞。用正式版（加到主畫面的 App）測。平常在試用版確認修改時，也可以先跑第 2–10 項（第 1、11 項只有正式版測得到）。

**準備**

- 兩支手機：**手機 A 登入老闆帳號**、**手機 B 登入測試用的顧客帳號**（第 1 項的版本號只有老闆帳號看得到）。只有一支手機的話，照最後的「同一支手機測」換帳號
- 顧客帳號固定用同一個測試帳號，不要用真的顧客帳號
- 紀錄測完都會清掉；測試帳號每次會在「📊 使用狀況」多算 1 位當天的使用人數，這是正常的

**老闆帳號（手機 A）**

- [ ] 1. 把 App 完全關掉再打開 → 入口頁「點一下進入」下面的小灰字是這次的版本號，例如「v1.6・2026/10/08 更新」（還是舊的就再關一次重開；完全沒有版本號，代表登入的不是老闆帳號）
- [ ] 2. 點「點一下進入」→ 底部「管理後台」→ 上方寫「正在管理 ○○館」→ 點平面圖上寫著幾條（不是「0 條」）的一區 → 往下滑，照片和路線列表出現
- [ ] 3. 點列表裡的一條路線 → 什麼都不改，按「儲存變更」→ 出現「已儲存」（確認後台存得進去，不會改到資料）

> ⚠️ 後台只點路線列表：不要點照片空白處（會跳出「新增路線」，跳出來就按「取消」），也不要碰「開放顧客留言」開關和「下次換線日」，這兩個一按就直接存。

**顧客帳號（手機 B）**

- [ ] 4. 把 App 完全關掉再打開 → 點「點一下進入」→ 選館頁點「明德館」（選寫「已上線」的館，不要選中壢館或 Spray Wall）→ 有平面圖、「全館難度分布」、四格難度篩選（全部／入門／進階／挑戰）和區域卡片 → 按左上「‹ 選擇攀岩館」→ 回到選館頁
- [ ] 5. 再點「明德館」→ 點一個有照片、有路線的區域（區域卡片右上角「0 / 數字」的數字不是 0）→ 照片上有路線點 → 按照片左上角「隱藏路線」→ 點消失 → 再按「顯示路線」→ 點回來
- [ ] 6. 點一條還沒有紀錄的路線（列表上沒有標嘗試中、完攀、Flash）→ 按「嘗試中」→ 出現「已記錄：嘗試中」→ 切到「紀錄」分頁按「清除紀錄」→ 按鈕變成「確定清除？…再按一次」，再按一次 → 出現「已清除紀錄」，卡片自動關掉
- [ ] 7. 再點一條路線 → 切到「留言」分頁 → 看到別人的留言或「還沒有人留言，分享你的 beta 吧。」，下面有輸入框和「送出」（不用真的留言，也不要按讚；寫「這條路線的留言已關閉」就換一條看）
- [ ] 8. 底部「我的紀錄」→ 統計格子、「攀爬日」月曆都有出來、沒有錯誤訊息（測試帳號沒有紀錄，數字是 0 或「–」是正常的）
- [ ] 9. 「我的紀錄」往下滑到有暱稱和帳號的那一格 → 按「登出」→ 出現「已登出」（先不要登入，直接做第 10 項）

**沒登入（手機 B）**

- [ ] 10. 底部「館內路線」→ 點一個區域 → 點一條路線 → 按「Flash」→ 跳到登入頁 → 用測試帳號登入 → 回到同一個區域（不會顯示「找不到這個區域」）。Flash 不會自動記上，不要再按

**離線（手機 B，正式版才有）**

- [ ] 11. 連著網路時：底部「館內路線」→ 點一個區域，等照片和路線出現 → 開飛航模式 → 把 App 完全關掉再打開 → 點「點一下進入」→ 同一間館 → 同一個區域 → 上方寫「目前沒有網路，顯示的是上次讀到的資料」，岩牆照片和路線列表照樣看得到（沒開過的區域會顯示「連不上網路」，是正常的；照片沒出來就截圖跟 Claude 說）→ 記得關掉飛航模式

**同一支手機測**：先用老闆帳號做 1–3 → 「我的紀錄」登出，登入測試帳號做 4–11 → 最後登出測試帳號、登回老闆帳號（下次第 1 項才看得到版本號）

**有一項不對時**

1. 截圖，跟 Claude 說是第幾項、看到什麼
2. 如果是不能登入、不能記錄、看不到路線這種大問題：登入 Netlify → 點 routemake → Deploys → 點上一個正常的版本 → **Publish deploy**，幾秒就退回上一版的畫面，再找 Claude 修。資料庫的變更不會跟著退回，請一併告訴 Claude 你退了版

## 0. 安全底線（每次更新正式版前都看）

**自動測試**

- `supabase/tests/10_permissions.sql`：模擬未登入、兩位顧客、定線員、店長、別館員工、老闆，逐項確認資料庫擋得住（目前 370 項），包括：

  - 私人心得（private_note）只有本人讀得到，員工、老闆都讀不到
  - 別人的紀錄、留言、影片不能改、不能刪
  - 員工只能管自己的館
- `tests/e2e/pwa-offline.test.mjs`「離線：…快取裡沒有 Supabase 個人資料」
- `tests/e2e/security.test.mjs`「正式版回應帶有防護標頭」
- `tests/e2e/auth.test.mjs`「登入後只會跳到站內頁面（擋掉外部網址）」

**手動確認**

1. GitHub 上看不到 `.env.local`（`.gitignore` 已排除 `.env*`）
2. 📱 Supabase SQL Editor 執行下面這段（只讀不改），每一列都要是「✅ 有 RLS」：
   ```sql
   select tablename as 資料表, case when rowsecurity then '✅ 有 RLS' else '❌ 沒有' end as 狀態
   from pg_tables where schemaname = 'public' order by 1;
   ```
3. 📱 用顧客 A 寫一則私人心得，再用店長帳號打開同一條路線 → 看不到那則心得

## 1. 註冊與登入

**自動測試**：`tests/e2e/auth.test.mjs`

- 註冊流程與錯誤提示（暱稱不帶入、不能跟登入帳號一樣）
- 註冊：以為卡住又按一次會直接登入；太久沒回應會提示
- 管理後台：未登入、沒權限、員工（顧客看不到資料庫指令；後台寫出正在管理哪一館）
- 登入頁：說明是路線專用帳號、明顯的註冊按鈕；看隱私權政策不會清掉打好的帳號密碼
- 暱稱跟登入帳號一樣的舊帳號：登入後請他換一個
- 登入後回到原本的區域：`tests/e2e/navigation.test.mjs`（見第 2 段）

**手機上怎麼測**

1. 登出 → 點「我的」→ 註冊，帳號用英數、密碼 8 碼
   → 應該看到：密碼預設顯示明碼；取暱稱的欄位是空的（打登入帳號會被擋）；完成後進到「我的」頁
2. 註冊頁點「隱私權政策」→ 看完按「看完了，回到註冊」
   → 應該看到：在面板裡看，關掉後打好的帳號密碼還在
3. 登出 → 用同一組帳號密碼登入
   → 應該看到：登入頁寫「跟入場的會員系統不同」、有「第一次用？註冊帳號」按鈕；登入成功，回到原本的頁面
4. 登出 → 進一個區域 → 點一條路線 → 按「Flash」→ 登入
   → 應該看到：回到同一個區域（不是「找不到這個區域」）；按左上「‹ 館名」回到館首頁
5. 故意打錯密碼
   → 應該看到：紅字提示「帳號或密碼錯誤」之類的中文訊息
6. 一般顧客帳號在網址列打 `/admin`
   → 應該看到：「管理後台是給原岩員工用的」說明，沒有資料庫指令，看不到後台

**📱 只能真機確認**

- 手機鍵盤輸入帳號時不會自動大寫第一個字、不會自動選字

## 2. 入口、選館、返回、版本號

**自動測試**：`tests/e2e/navigation.test.mjs`

- 入口頁、選館、返回都照順序

6. 用老闆帳號登入，看入口頁或「我的」頁最下面

## 10. 路線影片（含壓縮、身高與動作標籤）

**自動測試**：`tests/e2e/videos.test.mjs`、`supabase/tests/10_permissions.sql`「影片」

- 顧客分享影片、刪除自己的（要按兩次）；員工刪影片並記錄；下架路線影片一起刪除
- 未登入看得到影片、要登入才能分享；留言關閉且沒有影片時不顯示影片區
- 影片上傳前先壓縮成 720p（顯示進度），檔案變小、記錄壓縮後的大小
- 一支一列：說明（沒寫就是「某某的攀爬」）、誰・多久前、分享者的紀錄、片長、「身高 170–179cm・動態」
- 篩選鈕只出現影片裡有的身高、動作，一次選一個，再按一次回到全部；寫「2 / 4 支」；播放時只在篩選結果裡左右切換
- 分享時選身高（4 段）、動作（動態／靜態），都可以不選、再按一次取消；身高記在這支手機（分帳號記、登出時清掉），下次自動帶入；分享完篩選回到全部
- 資料庫只收固定的身高、動作選項；分享後不能改；未登入也看得到標籤
- 資料庫還沒執行 step25 時：影片照樣顯示、照樣分享（只是不帶標籤）

**手機上怎麼測**

1. 顧客登入 → 路線 → 「影片」分頁 → 分享攀爬影片 → 選一支手機拍的影片 → 選身高、動作 → 勾同意 → 「分享影片」
   → 應該看到：壓縮進度百分比，完成後影片出現在列表最上面，灰字寫「身高 ○○cm・動態」
2. 上面的篩選鈕按你剛選的身高（例如「170–179cm」）
   → 應該看到：只剩這個身高的影片，下面寫「○ / ○ 支」；再按一次回到全部
3. 關掉路線卡片再打開，再分享一支
   → 應該看到：身高已經幫你選好（上次選的），動作沒有選
4. 登出，換另一個帳號登入，分享影片
   → 應該看到：身高沒有預先選好（每個帳號分開記，登出時清掉）
5. 播放剛上傳的影片
   → 應該看到：畫面方向正確、有聲音，下面有身高・動作
6. 刪除自己的影片
   → 應該看到：先變成「確定刪除？再按一次」，按第二次影片才消失

**📱 只能真機確認**（壓縮靠手機瀏覽器，電腦模擬不到）

- iPhone Safari：壓縮能跑完、進度會動、上傳後有聲音、直式影片不會變橫的
- Android Chrome：同上
- 壓縮中切到別的 App 再回來：不會卡死（最差情況是重新選檔）
- 影片列的方形縮圖在 iPhone 上看得到第一格畫面（看不到會是黑底 ▶，也能播放）
- 360 寬的小手機：篩選鈕換行排得整齊、四格身高按鈕好按
