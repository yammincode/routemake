# 驗收清單

每個功能一段，分三部分：

- **自動測試**：Claude 每次 push 前都會跑（`npm run test:db`、`npm run build`、`npm run test:e2e`），全部通過才 push
- **手機上怎麼測**：3–5 步，照著點，對照「應該看到」
- **📱 只能真機確認**：自動測試模擬不到的，要你拿手機實際試

使用方式：

- **每次更新正式版後**：跑一遍下面的「每次必跑」（約 10 分鐘），再加上 Claude 列的「這次改動的項目」
- 平常改完功能：Claude 會同時更新這份清單裡對應的那一段
- 更新正式版前：Claude 會列出「這次要請你在手機上確認的項目」（從這份清單挑出跟這次改動有關的段落 + 所有 📱 項目中受影響的）
- 大改版或上線前：整份從頭跑一遍

測試帳號建議準備三個：**老闆**、**某館店長或定線員**、**一般顧客**（可以用兩支手機或一支手機 + 電腦）。

---

## 每次必跑（約 10 分鐘）

每次更新正式版後都跑這一份，確認最重要的幾條路沒有被改壞。用正式版（加到主畫面的 App）測，不要用試用版。

準備：**老闆帳號**一支手機、**測試用的顧客帳號**一支手機（或同一支手機登出再登入）。顧客帳號固定用同一個，不要用真的顧客帳號。

**老闆帳號**

- [ ] 1. 把 App 完全關掉再打開 → 入口頁 Logo 下方的版本號是這次的新版本（還是舊的就再關一次重開）
- [ ] 2. 底部「管理後台」→ 上方寫「正在管理 ○○館」→ 點平面圖上的一區 → 照片和路線列表出現
- [ ] 3. 點列表裡的一條路線 → 什麼都不改，按「儲存變更」→ 出現「已儲存」（確認後台存得進去，不會改到資料）

**顧客帳號**

- [ ] 4. 入口頁 → 選一間館 → 有平面圖和區域卡片 → 按左上「‹ 選擇攀岩館」→ 回到選館頁
- [ ] 5. 進一個區域 → 照片上有路線點 → 按照片左上角「隱藏路線」→ 點消失 → 再按「顯示路線」→ 點回來
- [ ] 6. 點一條路線 → 按「嘗試中」→ 出現「已記錄：嘗試中」→ 切到「紀錄」分頁按「清除紀錄」，再按一次確認 → 出現「已清除紀錄」（測完不留資料）
- [ ] 7. 再點一條路線 → 切到「留言」分頁 → 看得到留言區（不用真的留言）
- [ ] 8. 底部「我的紀錄」→ 統計和月曆正常顯示
- [ ] 9. 「我的紀錄」最下面按「登出」→ 再登入 → 登入成功

**沒登入**

- [ ] 10. 登出狀態進一個區域 → 點一條路線 → 按「Flash」→ 跳到登入頁 → 登入 → 回到同一個區域（不會顯示「找不到這個區域」）

**離線**

- [ ] 11. 開過一個區域後開飛航模式 → 把 App 關掉再打開 → 路線照樣看得到 → 記得關掉飛航模式

**有一項不對時**

1. 截圖，跟 Claude 說是第幾項、看到什麼
2. 如果是不能登入、不能記錄、看不到路線這種大問題：Netlify → 網站 → Deploys → 點上一個正常的版本 → **Publish deploy**，幾秒就退回上一版，再找 Claude 修

## 1. 註冊與登入

**自動測試**：`tests/e2e/auth.test.mjs`

- 註冊流程與錯誤提示（暱稱不帶入、不能跟登入帳號一樣）
- 註冊：以為卡住又按一次會直接登入；太久沒回應會提示
- 管理後台：未登入、沒權限、員工（顧客看不到資料庫指令；後台寫出正在管理哪一館）
- 登入頁：說明是路線專用帳號、明顯的註冊按鈕；看隱私權政策不會清掉打好的帳號密碼
- 暱稱跟登入帳號一樣的舊帳號：登入後請他換一個
- 登入後回到原本的區域：`tests/e2e/navigation.test.mjs`（見第 2 段）

**手機上怎麼測**

1. 登出 → 點「我的」→ 註冊，帳號用英數、密碼 8 碼
   → 應該看到：密碼預設顯示明碼；取暱稱的欄位是空的（打登入帳號會被擋）；完成後進到「我的」頁
2. 註冊頁點「隱私權政策」→ 看完按「看完了，回到註冊」
   → 應該看到：在面板裡看，關掉後打好的帳號密碼還在
3. 登出 → 用同一組帳號密碼登入
   → 應該看到：登入頁寫「跟入場的會員系統不同」、有「第一次用？註冊帳號」按鈕；登入成功，回到原本的頁面
4. 登出 → 進一個區域 → 點一條路線 → 按「Flash」→ 登入
   → 應該看到：回到同一個區域（不是「找不到這個區域」）；按左上「‹ 館名」回到館首頁
5. 故意打錯密碼
   → 應該看到：紅字提示「帳號或密碼錯誤」之類的中文訊息
6. 一般顧客帳號在網址列打 `/admin`
   → 應該看到：「管理後台是給原岩員工用的」說明，沒有資料庫指令，看不到後台

**📱 只能真機確認**

- 手機鍵盤輸入帳號時不會自動大寫第一個字、不會自動選字
