# 驗收清單

每個功能一段，分三部分：

- **自動測試**：Claude 每次 push 前都會跑（`npm run test:db`、`npm run build`、`npm run test:e2e`），全部通過才 push（只改說明文件 .md 時不用跑）
- **手機上怎麼測**：3–5 步，照著點，對照「應該看到」
- **📱 只能真機確認**：自動測試模擬不到的，要你拿手機實際試

使用方式：

- **每次更新正式版後**：試 Claude 列的「這次改動的項目」
- **每 3 次更新正式版**：再加跑下面的「定期必跑」（約 10 分鐘）。從 v2.2 起算，輪到的版本是 v2.5、v2.8、v3.1、v3.4…（上次跑的版本號加 0.3）；Claude 更新正式版時會說這次要不要跑
- 平常改完功能：Claude 會同時更新這份清單裡對應的那一段
- 更新正式版前：Claude 會列出「這次改動的項目」（從這份清單挑出跟這次改動有關的段落 + 受影響的 📱 項目）
- 大改版或上線前：整份從頭跑一遍

測試帳號建議準備三個：**老闆**、**某館店長或定線員**、**一般顧客**（可以用兩支手機或一支手機 + 電腦）。

---

## 定期必跑（每 3 次更新跑一次，約 10 分鐘）

輪到的版本（v2.5、v2.8、v3.1…）更新正式版後跑這一份，確認最重要的幾條路沒有被改壞。用正式版（加到主畫面的 App）測。平常在試用版確認修改時，也可以先跑第 2–10 項（第 1、11 項只有正式版測得到）。

**準備**

- 兩支手機：**手機 A 登入老闆帳號**、**手機 B 登入測試用的顧客帳號**（第 1 項的版本號只有老闆帳號看得到）。只有一支手機的話，照最後的「同一支手機測」換帳號
- 顧客帳號固定用同一個測試帳號，不要用真的顧客帳號
- 紀錄測完都會清掉；測試帳號每次會在「📊 使用狀況」多算 1 位當天的使用人數，這是正常的

**老闆帳號（手機 A）**

- [ ] 1. 把 App 完全關掉再打開 → 入口頁「點一下進入」下面的小灰字是這次的版本號，例如「v1.6・2026/10/08 更新」（還是舊的就再關一次重開；完全沒有版本號，代表登入的不是老闆帳號）
- [ ] 2. 點「點一下進入」→ 底部「管理後台」（老闆帳號有六個分頁，寫「後台」）→ 上方寫「正在管理 ○○館」→ 點平面圖上寫著幾條（不是「0 條」）的一區 → 往下滑，照片和路線列表出現
- [ ] 3. 點列表裡的一條路線 → 什麼都不改，按「儲存變更」→ 出現「已儲存」（確認後台存得進去，不會改到資料）

> ⚠️ 後台只點路線列表：不要點照片空白處（會跳出「新增路線」，跳出來就按「取消」），也不要碰「開放顧客留言」開關和「下次換線日」，這兩個一按就直接存。

**顧客帳號（手機 B）**

- [ ] 4. 把 App 完全關掉再打開 → 點「點一下進入」→ 選館頁點「明德館」（不要選寫「即將上線」的中壢館或 Spray Wall）→ 有平面圖、「全館難度分布」、四格難度篩選（全部／入門／進階／挑戰）和區域卡片 → 按左上「‹ 選擇攀岩館」→ 回到選館頁
- [ ] 5. 再點「明德館」→ 點一個有照片、有路線的區域（區域卡片右上角「0 / 數字」的數字不是 0）→ 照片上有路線點 → 按照片左上角「隱藏路線」→ 點消失 → 再按「顯示路線」→ 點回來
- [ ] 6. 點一條還沒有紀錄的路線（列表上沒有標嘗試中、完攀、Flash）→ 按「嘗試中」→ 出現「已記錄：嘗試中」→ 切到「紀錄」分頁按「清除紀錄」→ 按鈕變成「確定清除？…再按一次」，再按一次 → 出現「已清除紀錄」，卡片自動關掉
- [ ] 7. 再點一條路線 → 切到「留言」分頁 → 看到別人的留言或「還沒有人留言，分享你的 beta 吧。」，下面有輸入框和「送出」（不用真的留言，也不要按讚；寫「這條路線的留言已關閉」就換一條看）
- [ ] 8. 底部「我的紀錄」→ 統計格子、「攀爬日」月曆都有出來、沒有錯誤訊息（測試帳號沒有紀錄，數字是 0 或「–」是正常的）
- [ ] 9. 「我的紀錄」往下滑到有暱稱和帳號的那一格 → 按「登出」→ 出現「已登出」（先不要登入，直接做第 10 項；如果按鈕變成「還有 ○ 筆紀錄沒送出，登出會刪掉，再按一次」，代表有離線時記的紀錄還沒送出，先連上網路等上方的「正在送出」消失再登出）

**沒登入（手機 B）**

- [ ] 10. 底部「館內路線」→ 點一個區域 → 點一條路線 → 按「Flash」→ 跳到登入頁 → 用測試帳號登入 → 回到同一個區域（不會顯示「找不到這個區域」）。Flash 不會自動記上，不要再按

**離線（手機 B，正式版才有）**

- [ ] 11. 連著網路時：底部「館內路線」→ 點一個區域，等照片和路線出現 → 開飛航模式 → 把 App 完全關掉再打開 → 點「點一下進入」→ 同一間館 → 同一個區域 → 上方寫「目前沒有網路，顯示的是上次讀到的資料」，岩牆照片和路線列表照樣看得到（沒開過的區域會顯示「連不上網路」，是正常的；照片沒出來就截圖跟 Claude 說）→ 記得關掉飛航模式

**同一支手機測**：先用老闆帳號做 1–3 → 「我的紀錄」登出，登入測試帳號做 4–11 → 最後登出測試帳號、登回老闆帳號（下次第 1 項才看得到版本號）

**有一項不對時**

1. 截圖，跟 Claude 說是第幾項、看到什麼
2. 如果是不能登入、不能記錄、看不到路線這種大問題：登入 Netlify → 點 routemake → Deploys → 點上一個正常的版本 → **Publish deploy**，幾秒就退回上一版的畫面，再找 Claude 修。資料庫的變更不會跟著退回，請一併告訴 Claude 你退了版

## 0. 安全底線（每次更新正式版前都看）

## 1. 註冊與登入

**自動測試**：`tests/e2e/auth.test.mjs`

- 註冊流程與錯誤提示（暱稱不帶入、不能跟登入帳號一樣）
- 註冊：以為卡住又按一次會直接登入；太久沒回應會提示
- 管理後台：未登入、沒權限、員工（顧客看不到資料庫指令；後台寫出正在管理哪一館）
- 登入頁：說明是路線專用帳號、明顯的註冊按鈕；看隱私權政策不會清掉打好的帳號密碼
- 暱稱跟登入帳號一樣的舊帳號：登入後請他換一個
- 登入後只會跳到站內頁面：`//`、`/\`、`https://`，以及整理路徑後才變成外部網址的 `/.//`、`/%2e//`、`/x/..//` 都擋；已經登入的人打開這種連結、改暱稱後也留在站內
- 暱稱不能冒充館方：顧客取「原岩官方」會說明原因；員工可以用「定線」（簡體、館長、櫃檯、「Staff Amy」、看不見的字元、只有空白也擋；一般表情符號 ❤️🧗‍♀️1️⃣ 可以用，見 10_permissions.sql「暱稱」）
- 登出：還有紀錄沒送出時要再按一次；沒網路又登入過期時最多等 3 秒就登出、手機裡的登入一定清掉（`tests/e2e/offline-sync.test.mjs`）

   → 應該看到：回到同一個區域（不是「找不到這個區域」）；按左上「‹ 館名」回到館首頁

## 4. 區域順序、平面圖（立體／平面）、區域改名

**自動測試**：`tests/e2e/zone-order.test.mjs`、`tests/e2e/zone-rename.test.mjs`、`tests/e2e/plan3d.test.mjs`

- 平面圖預設「立體」（2.5D 斜俯視，像建築模型）：每區是方塊，路線越多越高；頂面顏色照完成度；後面的外牆半透明、門口留空；櫃台、大門是矮方塊
- 7 天內換線的區：平面圖（立體、平面、後台都一樣）不畫虛線框，右下角也沒有「7 天內換線」說明（換線寫在區域卡片上；報讀照樣唸「○ 天後換線」）
- 前面的方塊再高也不會把後面的區擋掉：小區正後面那區剛換線（0 條）、前面那區很多條時，整張圖的高度會自動壓低（還是越多越高；明德區域小，方塊會比其他館矮），每區頂面至少露出 6 成；南港 1F、2F 的方塊用同一個高度比例（跨樓層也是越多越高）；前後順序照真的位置畫（右邊、前面的蓋住左邊、後面的；貼牆的區不會被半透明的牆蓋到；平板、電腦視窗拉大拉小後也一樣）
- 區名正立、字的大小固定（小手機也一樣大）；位置跟平面圖一樣在那一區旁邊（區名在區裡面的大區，跟著頂面浮上去）；前面的方塊浮起來蓋到那個位置時，區名會挪到旁邊，最多一半蓋在別區的方塊上；太擠會自動推開，離原本的位置遠了有指引線；改過的長名字超過 5 個字截短加「…」（剛好 5 個字不截）；所有區都改成長名字也不會疊在一起

## 22. 長耐力區域（照順序標點、爬到第幾點、照比例算分）

## 23. 區域頁左右滑動換區

**自動測試**：`tests/e2e/zone-swipe.test.mjs`

- 刪除我的帳號（我的紀錄 → 帳號最下面，員工沒有）：列出會刪掉什麼，輸入密碼；密碼錯寫「密碼不對」、什麼都不刪；對了先刪影片檔再刪帳號，登出回我的紀錄

- 重設碼用掉的操作紀錄記在產生重設碼的那一館（那館店長看得到）；員工的帳號只有老闆能產生、作廢重設碼；定線長不能產生、作廢
- 操作紀錄多一個「帳號」篩選：停權、解除、刪帳號、產生重設碼、用重設碼設新密碼
- 隱私權政策、留言與影片規範跟著改（可以自己刪帳號、忘記密碼怎麼辦、停權的規則）
