# 試用版與正式版

| | 試用版 | 正式版 |
|---|---|---|
| 在哪裡 | 你的電腦（PowerShell 執行） | https://routemake.netlify.app |
| 程式來自 | GitHub 分支 `claude/happy-goldberg-szmqwa` | GitHub 分支 `main` |
| 更新方式 | 執行 `scripts\trial.ps1`，自動下載最新程式 | 你說「更新正式版」，Claude 把試用版合併到 `main` |
| 花 Netlify 額度 | 不花 | 每次約 15 credits |
| 資料庫 | 同一個 Supabase（試用時新增的資料正式版也看得到） | 同一個 Supabase |

## 第一次準備（只要做一次）

1. 安裝 Git 和 Node.js：打開 PowerShell，輸入
   ```powershell
   winget install Git.Git
   winget install OpenJS.NodeJS.LTS
   ```
   裝完**關掉 PowerShell 再重開**。
2. 下載程式（放在「文件」資料夾）：
   ```powershell
   cd $HOME\Documents
   git clone https://github.com/yammincode/routemake.git
   ```

## 每次試用

```powershell
cd $HOME\Documents\routemake
powershell -ExecutionPolicy Bypass -File scripts\trial.ps1
```

- 第一次會請你貼上 Supabase 的 publishable key（`sb_publishable_` 開頭）
- 看到「啟動試用版」後：
  - 電腦開 http://localhost:3000
  - 手機（同一個 Wi-Fi）開畫面上顯示的 `http://192.168.x.x:3000`
- Windows 跳出防火牆詢問時按「允許」
- 停止：在 PowerShell 視窗按 `Ctrl + C`

試用版沒有離線功能和「加到主畫面」（這兩個只有正式版有），其他功能都一樣。

## 更新正式版

試用確認沒問題後，跟 Claude 說「**更新正式版**」。Claude 會把目前的試用版合併到 `main`，Netlify 只會部署這一次。
