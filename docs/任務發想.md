# 任務發想（路線系統5 和使用者一起發想，給路線系統7 做提案用）

10/16 開始。這份只放「有哪些任務」的點子，怎麼做（畫面、資料庫、徽章樣子）由路線系統7 提案。

## 先講好的前提
- **防作弊**：沿用待辦裡的決定，到館掃碼打卡後，同一天同一間館記的完攀才算（10/16：店裡放螢幕顯示會換的 QR、**上線前的舊紀錄不算**、兩館各打一次、員工可補打卡；詳見 docs/待辦.md「到館打卡」）。下面標 🏠 的任務都要靠打卡才可信。
- **徽章分等級**（路線系統7 加的）：普通 → 銅 → 銀 → 金 → 琉璃。下面的「等級」欄是建議門檻，可以調。
- **資料**：✅ 現在的資料就算得出來；🆕 要記新的東西才算得出來（例如打卡時間）。

## 7. 限時活動（老闆在營運頁開，一段時間才有）

| 任務 | 怎麼算 | 備註 |
|---|---|---|
| 主題月（例：十月指力月） | 活動期間有「指力」標籤的路線完攀 N 條 | 每月換主題，拿限定徽章 |
| 顏色收集（例：萬聖節橘黑） | 活動期間完攀 N 條橘色、黑色岩點的路線 | 用路線的岩點顏色 |
| 館慶／新館開幕 | 活動期間在那間館完攀 N 條 | 中壢開幕可以用 |
| 夥伴同樂 | 選某隻原岩夥伴的人，活動期間一起累積 | 團體任務，大家一起推進度條 |

## 想跟老闆確認的方向
1. 任務的重點想推哪一種：**難度成長**、**常來**、**跑不同館**，還是**社群**？（會影響第一批放哪些）
2. 社群類（按讚、分享）容易被好友互刷，要不要放？放的話只算「不同的人」。
3. 限時活動要不要第一批就做，還是先做常駐的、之後再加？
4. 獎勵只有徽章和背景牆，還是有些任務要搭配櫃檯實體獎品（像大滿貫兌換）？

## 已決定
- 10/16：**第一批優先「難度成長」（第 1 類）和「常來」（第 4 類）**；**社群類（第 6 類）先不放**（按讚、分享容易被好友互刷）。探索、風格、換線、限時活動還沒決定（第一批先不放，之後再討論）。
- 第一批候選（等老闆確認門檻）：V○ 高手、突破！、一發入魂、苦主終結者；攀爬日、每週報到、月月見（早鳥／夜貓要打卡時間，等打卡做好再加）。
